# Attribution discipline

## Use roles, not identities

Launch signer. Fee recipient. Funder. Observed controller. Deployer of
record. These describe what was observed. Keep using them until stronger
evidence supports something more specific.

## What does not establish common ownership

None of the following, alone or stacked:

- shared funding source
- a shared router, aggregator or exchange
- deposits to the same exchange
- suspicious timing
- deterministic (CREATE2) deployment from the same factory
- the same settlement destination

Each is consistent with common control **and** with ordinary shared
infrastructure. Say which readings survive.

## Language that keeps the claim honest

- Sell-then-rebuy routing → **market-mediated redistribution**, unless
  common control is independently established.
- Gross received value → **proceeds**, not profit. Profit needs a
  defensible cost basis, the material flows, fees, and retained inventory.
- An address that funded another → **funder**, not owner.
- An exchange deposit → the end of the trace, not evidence of a sale, a
  fiat withdrawal, or a final beneficiary.

## Personal identity

Do not conduct broad personal-identity searches by default. Keep public
attribution narrow and tied to authenticated project-control evidence —
something the project itself published or signed.

A contract's control is usually the decision-relevant question, and it can
almost always be answered without naming a person.
